# Torrent-LLM — Claude Code Project Config

This project has four slash-command skills available in `.claude/skills/`.
They are automatically loaded when you open this repo in Claude Code.

## Available Skills

### /new-issue
Create a well-structured GitHub issue from a one-line description.
Auto-detects type (bug/feature/chore/docs), generates acceptance criteria, and adds the issue to the project board as Backlog.

### /start-task
Pick up an assigned issue from the board, branch, implement, commit, and raise a PR — all in one guided flow.

### /project-research
Deep-research a project idea: competitors, features, task breakdown, tech recommendations, and risk log. Writes output to `docs/research.md`.

### /plan-project
Set up or update the GitHub Project board: user stories, sprint milestones, and teammate assignments.
